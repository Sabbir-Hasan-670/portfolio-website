        🎯 Tracking & Analytics Settings

        Manage GA4, Google Tag Manager, Meta Pixel, Clarity, Google Search Console & Cookie Consent

        📊 Google Analytics 4

        💡 Where to find: Google Analytics > Admin > Data Streams > Web stream.

        ⚠️ Notice: If you load GA4 inside Google Tag Manager, leave this direct GA4 toggle disabled to prevent double-counting traffic.

        🏷️ Google Tag Manager

        💡 Injects the official GTM script in <head> and noscript iframe in <body>.

        🎯 Meta (Facebook) Pixel

        💡 Where to find: Meta Events Manager > Data Sources > Pixel ID. Automatically fires PageView.

        🔥 Microsoft Clarity (Heatmaps)

        💡 Where to find: Clarity Settings > Overview > Project ID. Captures session recordings and click heatmaps.

        🔍 Google Search Console Verification

        💡 Paste either the entire meta tag from Google Search Console or just the content code string.

        🍪 Cookie Consent & Consent Mode v2

        When enabled, analytics storage and ad storage are denied by default. Trackers are only activated after the visitor gives consent via a discreet dark-glass cookie banner.

        Fully compatible with European GDPR & Google Consent Mode v2 standards.

        ⚡ Custom Injections (Advanced / Admin Only)

        🔑 Google Analytics 4 Data API (Optional / Remote Reporting)

        Connect your GA4 property directly to pull Google-side statistics alongside your first-party analytics.

        Quick 4-Step GA4 Data API Setup:

        1. Open Google Cloud Console and create or select a project.
        2. Enable the Google Analytics Data API from the API Library.
        3. Create a Service Account, create a JSON key, and download it. Paste its entire JSON content above.
        4. In Google Analytics > Admin > Property Access Management, add the service account email with the Viewer role.
